# 노매치와 안전한 종료 흐름 제안

## 목표

노매치, 선택 없음, 공개 거절, 타임아웃, 차단, 제거와 취소는 승인된 정상 사적 결과다. 종료 경험은 상대의 선택·수·이유를 노출하거나 사용자를 실패·탈락으로 평가하지 않는다.

## 결과별 제안

| 상황 | 사용자에게 보여 줄 정보 | 보여 주지 않을 정보 | 다음 행동 |
| --- | --- | --- | --- |
| 초기 관심 상호 없음 | 제한 공개가 열리지 않았고 최종 선택은 계속 가능 | 누가 누구를 선택했는지, 수, 이유 | 최종 선택/없음 |
| 공개 동의 없음 | 이번 공개는 진행되지 않음 | 누가 거절·만료·오류였는지 | 최종 선택/없음, 차단·신고 |
| 최종 상호 없음 | 다음 10분 음성은 열리지 않음 | 상대 선택, 거절 이유, 타임아웃 원인 | 공통 종료, 피드백, 안전 행동 |
| 내가 없음 선택 | 내 선택이 없음으로 제출됨 | 상대 관심 여부 | 공통 종료 |
| 제출 타임아웃 | 이번 단계의 내 선택이 없음으로 닫혔는지 명료하게 안내 | 상대 제출 상태 | 공통 종료/지원 |
| 차단 | 공개와 진행이 중단되고 이후 접근이 제한됨 | 차단 사실의 상대 통지·상대 제재 상세 | 나가기, 신고 선택, 지원 |
| 상대 미입장 | 쌍 음성에 현재 연결되지 않았고 권한 만료 시각 | 이유·상대 기기 상태 | 기다리기 범위, 종료, 신고/지원 |
| 운영 취소 | 세션이 안전/운영 조건으로 종료됨 | 신고자·개인 책임·민감 이유 | 무벌 재예약, 지원 |

## 공통 종료 순서

1. 현재 결과를 한 문장으로 설명한다.
2. 타인의 선택이나 이유를 제공하지 않는 이유를 짧게 설명한다.
3. 내 데이터·권한의 다음 상태를 알려 준다.
4. 안전하게 나가기, 차단, 신고, 지원을 제공한다.
5. 선택적 피드백과 다음 예약을 분리한다.

## 한국어 핵심 마이크로카피

### 제한 공개 없음

- 제목: “이번 공개 단계에서 보여 줄 정보는 없어요.”
- 본문: “누가 어떤 선택을 했는지는 서로에게 공개되지 않아요. 최종 선택은 그대로 진행할 수 있어요.”
- 행동: “최종 선택으로”, “안전 메뉴”.

### 최종 노매치

- 제목: “이번에는 다음 음성 대화가 열리지 않았어요.”
- 본문: “선택 내용과 이유는 모두 비공개예요. 여기까지 참여한 경험은 다른 사람에게 평가나 점수로 남지 않아요.”
- 행동: “세션 마치기”, “차단·신고”, “의견 남기기”.

### 내가 아무도 선택하지 않음

- 제목: “아무도 선택하지 않고 마쳤어요.”
- 본문: “선택하지 않는 것도 정상적인 선택이에요. 다른 사람에게 선택 이유는 보이지 않아요.”

### 공개 거절

- 제목: “공개하지 않아도 괜찮아요.”
- 본문: “이유를 입력할 필요가 없고 상대에게 거절 이유가 전달되지 않아요. 이미 본 정보는 되돌릴 수 없지만 새 접근은 중단할 수 있어요.”

### 운영 취소

- 제목: “이번 세션을 안전하게 종료했어요.”
- 본문: “개별 참가자의 사유는 공개하지 않아요. 불이익 없이 다른 시간을 선택할 수 있어요.”

## 추론 방지 규칙

- 결과별 화면 체류 시간, 알림 시점, 버튼 수를 과도하게 다르게 만들어 결과를 간접 추론시키지 않는다.
- “아직”, “거의”, “상대가”, “한 표”처럼 타인의 선택을 암시하는 표현을 쓰지 않는다.
- 노매치 알림을 잠금 화면·메시지 미리보기에 넣지 않는다.
- 공개 없음과 노매치를 재시도·설득·결제 기회로 표현하지 않는다.
- 피드백 질문에서 특정 상대의 선택 이유를 추정하도록 묻지 않는다.

## 차단·신고·안전 종료

- 차단은 즉시 공개·진행을 중단하고 상대에게 차단자를 알리지 않는다.
- 신고는 차단과 분리한다. 신고 없이 차단하거나 나갈 수 있다.
- 긴급한 위험은 제품 지원과 별도 긴급 도움 안내로 연결하되 법적 결과를 약속하지 않는다.
- 신고 접수 후 “처벌 완료” 대신 “접수되었고 검토 상태를 확인할 수 있어요”라고 말한다.
- 제재와 이의 제기는 승인된 사람 검토·독립 이의 절차를 전제로 한다.

## 쌍 음성 종료

- 10분 종료 임박을 차분히 알리고 자동 연락처 교환이나 텍스트를 열지 않는다.
- 어느 쪽이든 나가기·차단·신고·동의 철회가 가능하다.
- 상대가 오지 않아도 거절로 단정하지 않고 권한 만료와 내 종료 선택만 설명한다.

## 사용성 확인

- 참가자가 노매치 후 상대 선택을 특정하지 않고 결과를 설명할 수 있는가?
- 공개 거절이 이유 설명 의무나 향후 불이익으로 이해되지 않는가?
- 10초 안에 나가기·차단·신고를 구분하고 선택할 수 있는가?
- 스크린리더와 200% 확대에서 결과·안전 행동 순서가 유지되는가?

## 승인 경계

문구, 결과 화면 통합 여부, 알림 시점, 차단·신고 확인 방식과 쌍 음성 대기 시간은 제안이다. D-024 승인과 한국어 사용자 검증 전 확정하지 않는다.
