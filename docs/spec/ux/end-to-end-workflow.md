# MVP 종단 사용자 워크플로

## 범위

이 흐름은 승인된 [MVP 범위](../mvp-scope.md), [세션 규칙](../session-experience.md), [공개 규칙](../progressive-disclosure.md)을 화면 수준 제안으로 연결한다. 단계 이름은 UX 검토용이며 라우트, API, DTO, 데이터 상태 또는 실시간 이벤트 이름이 아니다.

## 핵심 분기

### 미충원·입장 실패

- T-24h에 여섯 명이 확인되지 않거나 시작 시 여섯 명이 입장 자격을 통과하지 못하면 세션을 시작하지 않는다.
- 개인의 결석·자격·제재 정보를 다른 참가자에게 공개하지 않는다.
- 문구 제안: “이번 세션은 시작 조건을 충족하지 못해 취소됐어요. 불이익 없이 다른 시간을 선택할 수 있어요.”

### 시작 후 한 명 이탈

1. 운영자가 세션을 일시정지한다.
2. 남은 다섯 명에게 계속 진행 조건과 영향만 개별적으로 설명한다.
3. 호환 규칙이 깨지지 않고 다섯 명 모두 명시 동의할 때만 계속한다.
4. 한 명이라도 동의하지 않거나 조건이 깨지면 취소·재예약한다.

### 공개 대상 없음 또는 거절

- 상호 초기 관심이 없으면 공개 단계를 일반 안내로 지나가며 누구의 선택도 설명하지 않는다.
- 공개 동의 거절·만료·미디어 불가는 이유를 상대에게 알리지 않는다.
- 최종 선택은 공개 여부와 관계없이 0–1명 또는 없음으로 진행한다.

### 차단·신고·나가기

- 차단은 공개와 향후 진행 권한을 양방향으로 즉시 끊되 차단자를 노출하지 않는다.
- 신고는 즉시 안전 행동 뒤 최소 맥락으로 제출하고, 필요하면 세션 후 보완한다.
- 나가기는 신고를 요구하지 않으며 긴급 도움과 운영 지원을 분리한다.

## 기술 복구 연결

새로고침·백그라운드·네트워크 전환은 [실패 및 복구 흐름](failure-and-recovery-workflow.md)을 따른다. 복구 시 현재 권한을 다시 확인하며 만료된 공개·발화·선택 권한을 복원하지 않는다.
