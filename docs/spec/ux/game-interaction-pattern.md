# 세 게임 재사용 상호작용 패턴 제안

## 승인된 게임과 제안 범위

승인된 첫 세션 형식은 익명 선택·주인 맞히기, 단서 주인 맞히기, 협력 행동 시나리오다. 이 문서는 세 형식이 공유할 셸과 접근성 행동을 제안한다. 점수, 승자, 성격 진단, 외모 평가, 임시 소그룹 또는 소셜 디덕션을 추가하지 않는다.

## 공통 한 사이클

| 단계 | 화면이 먼저 알려야 할 것 | 주 행동 | 보조·안전 행동 | 종료 조건 |
| --- | --- | --- | --- | --- |
| 소개 | 목적, 예상 시간, 공개 범위, 금지 주제 | 시작 준비 | 예시, 규칙 다시 보기, 나가기·신고 | 모두에게 지시 제시 |
| 생각 | 질문/자료, 남은 생각 시간, 답변 방식 | 사적 입력 또는 준비 | 패스, 반복, 생각 시간, 텍스트 | 제출 또는 시간 종료 |
| 제출 | 무엇이 공개될지, 수정 가능 여부 | 제출 | 지우기, 없음, 나가기·신고 | 권위 있는 접수 확인 |
| 공유 | 지금 공개되는 내용과 청중 | 듣기/읽기 | 음소거, 접근성 설명, 신고 | 항목 공개 완료 |
| 차례 | 누구의 차례인지, 남은 시간 | 말하기/선택 | 패스, 텍스트, 반복 | 차례 종료 |
| 회고 | 정답/점수 없이 대화 씨앗 | 짧은 후속 대화 | 넘어가기, 신고 | 다음 항목/게임 |
| 전환 | 다음 단계, 휴식/회복 여부 | 계속 | 도움, 나가기 | 다음 게임 셸 로드 |

## 공통 모바일 셸

1. 상단 고정: 게임명, 항목 진행, 청중, 남은 시간, 연결 상태.
2. 본문: 한 화면 지시, 한 가지 예시, 현재 자료, 내 차례/행동.
3. 응답 영역: 주 행동 하나, 패스·반복·생각 시간·텍스트를 같은 수준에서 찾을 수 있게 배치.
4. 하단 고정: 마이크/음소거, 나가기, 안전 메뉴. 신고는 더보기 안에서도 한 단계로 도달한다.
5. 참가자 표현: 발화 가능/음소거/연결 상태만 중립적으로 표시하고 순위·인기도·정답 수를 표시하지 않는다.

## 게임별 변형

### 게임 1 — 익명 선택과 주인 맞히기

- 개인 선택은 공유 전에 비공개로 제출한다.
- 공유 화면은 답변만 보여 주고 시스템이 소유자를 미리 드러내지 않는다.
- 참가자 추측은 점수나 공개 정답률 없이 대화 시작 용도로만 사용한다.
- 문구 제안: “정답 경쟁이 아니에요. 떠오르는 사람을 가볍게 골라 주세요. 패스해도 괜찮아요.”

### 게임 2 — 단서 주인 맞히기

- 승인된 한 단서 또는 비얼굴 이미지만 현재 세션 청중에게 표시한다.
- 소유자는 제출 전 공개 범위와 대체/생략 경로를 확인한다.
- 미디어가 보류·거절·불러오기 실패이면 텍스트 대체 또는 항목 건너뛰기를 제공한다.
- 문구 제안: “이 단서는 지금 이 그룹에만 보여요. 원하지 않으면 다른 단서로 바꿀 수 있어요.”

### 게임 3 — 협력 행동 시나리오

- 공통 목표와 경계를 먼저 제시하고 각자 짧은 차례를 가진다.
- 한 사람의 합의 강요, 도덕 점수, 진단, 승패를 만들지 않는다.
- 운영 지원은 말이 겹치거나 독점될 때 중립적으로 다음 차례를 안내한다.
- 문구 제안: “서로 다른 선택을 모아 하나의 계획을 만들어 보세요. 합의하지 않아도 괜찮아요.”

## 접근성·압력 완화

- 지시는 한국어 짧은 문장, 목록, 예시로 제공하고 음성에만 의존하지 않는다.
- 시간 추가는 개인 능력이나 장애를 공개하지 않는 방식으로 제공한다.
- 텍스트 응답이 그룹에 읽히거나 표시되는 시점과 청중을 제출 전에 알린다.
- 스크린리더는 타이머 매초를 읽지 않고 의미 있는 임박·종료만 알린다.
- 색만으로 차례·제출·연결 상태를 구분하지 않는다.
- 패스는 빈 답이나 낮은 관심으로 기록·표현하지 않는다.

## 기술·안전 실패

- 네트워크 지연 시 입력을 중복 공개하지 않고 현재 항목 상태를 다시 확인한다.
- 콘텐츠가 중단되면 이유 상세나 신고자를 노출하지 않고 대체 항목 또는 안전한 전환을 안내한다.
- 참가자 이탈 시 운영 일시정지와 승인된 계속/취소 규칙을 따른다.
- 복구를 위해 동의·안전 시간을 줄이거나 다음 단계를 건너뛰지 않는다.

## 검증 질문

- 세 게임 모두 새 패턴을 배우지 않고 같은 위치에서 패스·반복·신고를 찾는가?
- 사적 입력이 언제 누구에게 공개되는지 정확히 설명하는가?
- 말이 느린 사람, 키보드/스크린리더 사용자, 텍스트 대안 사용자가 같은 핵심 과업을 완료하는가?
- 참여 집중을 완화하되 조용한 사람이나 말 많은 사람을 공개적으로 평가하지 않는가?

## 승인 경계

정확한 제어 위치, 타이머, 턴 배정, 텍스트 표시, 시간 추가와 운영 개입은 D-024 승인 전 미확정이다. 콘텐츠 자체는 별도 편집·안전·권리 검토를 거친 버전만 사용한다.
