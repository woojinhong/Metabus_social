# 모바일 상호작용 규칙 제안

## 범위

현재 iOS Safari와 Android Chrome의 세로형 Web/PWA를 우선한다. 동일한 여정을 강제된 동일 레이아웃으로 만들지 않으며, 네이티브 앱·카메라·백그라운드 통화 기능을 추가하지 않는다. 실제 배치와 치수는 D-024 승인 전 최종 디자인이 아니다.

## 라이브 세션 셸 정보 우선순위

1. 현재 단계, 청중/공개 범위, 남은 시간, 연결 상태.
2. 지금 해야 할 한 가지 과업과 짧은 예시.
3. 참가자 음성 상태와 현재 차례.
4. 마이크/음소거, 패스 또는 제출 같은 단계 행동.
5. 나가기, 차단, 신고, 도움.

이 다섯 영역은 핵심 단계에서 스크롤 깊이, 호버 또는 숨은 제스처에만 의존하지 않는다.

## 세로형 구조 제안

| 영역 | 고정/스크롤 | 포함 정보 | 규칙 |
| --- | --- | --- | --- |
| 상단 상태줄 | 고정 | 단계, 청중, 시간, 연결 | 한 줄 요약과 확장 가능한 설명; 색만 사용 금지 |
| 현재 과업 | 짧은 스크롤 | 지시, 예시, 공개 범위 | 한 화면 분량을 목표로 하고 긴 규칙은 접어도 핵심은 유지 |
| 참가자 상태 | 제한 스크롤 | 닉네임, 발화/음소거/연결 | 순위·인기·선택·정답·신고 상태 표시 금지 |
| 응답/선택 | 과업 근처 | 주 행동, 편집/없음, 패스·텍스트 | 키보드가 열려도 제출 효과와 안전 행동에 접근 가능 |
| 하단 제어 | 고정 또는 즉시 복귀 | 마이크, 나가기, 안전 메뉴 | 안전 영역을 존중하고 오조작 확인은 위험도에 비례 |

## 터치·키보드·화면 크기

- 핵심 터치 표적은 최소 44×44 CSS 픽셀의 조작 영역을 제안하며 인접 위험 행동 사이에 여백을 둔다.
- hover 전용 정보와 정밀 드래그를 금지한다. 탭, 키보드, 스위치, 스크린리더로 같은 결과에 도달한다.
- 200% 확대와 작은 뷰포트에서 가로 스크롤 없이 핵심 순서가 유지되어야 한다.
- 소프트 키보드가 관심 선택, 텍스트 대안, 신고 입력의 제출·취소·안전 종료를 가리지 않아야 한다.
- 가로 회전은 선택 사항이며 회전만으로 권한·입력·타이머가 초기화되지 않는다.

## 마이크와 오디오

- 마이크 또는 가청 미디어 시작 전 명시적 사용자 제스처를 요구한다.
- 현재 마이크 상태와 듣는 청중을 텍스트+아이콘으로 지속 표시한다.
- 블루투스·스피커·유선 경로 변경 뒤 짧은 확인과 재시험을 제공한다.
- 백그라운드, 화면 잠금, 수신 전화 복귀 시 자동 발화를 시작하지 않고 상태를 다시 확인한다.
- 카메라 권한은 요청하지 않는다. 녹음 중이라는 오해를 만들 수 있는 시각 요소를 피한다.

## 단계별 모바일 행동

| 단계 | 주 행동 | 항상 가능한 대안/안전 | 작은 화면 보호 |
| --- | --- | --- | --- |
| 대기 | 준비 확인 | 나가기, 도움, 규칙 | 다른 참가자의 출석 상세를 노출하지 않음 |
| 게임 | 응답/말하기 | 패스, 반복, 생각 시간, 텍스트, 신고 | 지시와 응답을 같은 맥락에 유지 |
| 자유 대화 | 마이크/음소거 | 패스, 나가기, 신고 | 참가자 목록이 안전 제어를 밀어내지 않음 |
| 초기 관심 | 0–2명/없음 | 편집, 나가기, 차단 | 어깨너머 보호, 제출 전 비공개 설명 |
| 공개 동의 | 동의/거절 | 캡처 한계, 지원, 차단 | 리소스·청중·목적·만료를 행동 앞에 표시 |
| 공개 보기 | 닫기/철회 | 신고, 차단 | 앱 전환기·캐시·미리보기에 보호 정보 최소화 |
| 최종 선택 | 0–1명/없음 | 차단, 나가기 | 상대 선택 암시 금지 |
| 쌍 음성 | 마이크/종료 | 차단, 신고, 철회 | 남은 시간과 음성만 허용됨을 고정 표시 |

## 관심·공개 프라이버시

- 이름 선택 화면은 화면 녹화·어깨너머 노출을 완전히 막을 수 없음을 과장 없이 알린다.
- 앱 전환기와 잠금 화면 미리보기에 참가자 얼굴, 관심, 결과, 안전 사례 정보를 넣지 않는다.
- 브라우저 뒤로가기는 제출·동의를 되돌리는 것으로 오해되지 않게 현재 권한을 다시 확인한다.
- 공개 미디어는 확대·저장·공유 기능을 제공하지 않지만 로컬 캡처 방지를 보장하지 않는다.
- 푸시를 MVP에 추가하지 않으며 거래 알림의 미리보기는 참가자 신원·관심·공개·사례 세부를 제외한다.

## 연결·백그라운드 복구

- 연결 저하 배너는 현재 마이크와 행동 제한을 함께 설명한다.
- 다시 연결 중에는 제출·동의·공개 제어를 보수적으로 제한하고 나가기·지원·신고를 유지한다.
- 복귀 후 현재 단계·청중·마이크·권한을 한 번에 확인시킨다.
- OS가 음성을 중단했으면 명시적 재개 동작을 요구한다.
- 복구 기준과 실패 경로는 [실패 및 복구](failure-and-recovery-workflow.md)를 따른다.

## 접근성

- 포커스 순서는 상태 → 현재 과업 → 응답 → 제어 → 안전이며 시각 순서와 일치한다.
- 타이머는 매초 읽지 않고 시작, 의미 있는 임박, 종료만 알린다.
- 연결·마이크·차례·선택 상태는 색·진동·소리만으로 구분하지 않는다.
- 감소 동작에서는 자동 전환 애니메이션을 제거하고 내용 변화에 초점을 이동하지 않는다.
- 텍스트 확대 뒤 고정 바가 본문이나 오류 메시지를 가리지 않는다.

## 실기기 검증 제안

현재/구형 iPhone, 최근 Samsung Galaxy, Bluetooth 이어버드, 스피커, 유선 헤드셋, Wi-Fi·LTE/5G 전환에서 핵심 과업을 검증한다. 승인된 수치 게이트는 [웹·모바일 경험](../web-mobile-experience.md)을 그대로 적용하며 이 문서에서 변경하지 않는다.

## 승인 경계

고정 영역, 44×44 제안, 제어 위치, 뒤로가기, 키보드, 앱 전환기 처리와 세로/가로 적응은 프로토타입·실기기 검증 및 D-024 승인 전 미확정이다.
