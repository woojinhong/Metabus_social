# 화면 및 상태 모델

## 사용 규칙

화면 키는 리뷰와 와이어프레임을 위한 로컬 표기다. 라우트, 페이지 권한, API 상태, 데이터 열, enum 또는 실시간 상태 머신을 정의하지 않는다. 기존 [화면 후보 목록](screen-inventory.md)을 중복 확정하지 않고 상태 검토 단위로 확장한다.

2026-07-27 소유자가 승인한 UX-OQ-001 기준에서 `P10`은 입장부터 종료까지 현재 단계,
청중/공개 범위, 남은 시간, 연결, 마이크, 참가자 음성 상태, 현재 과업과
안전/나가기를 유지하는 영속 라이브 세션 셸이다. 규칙/소개는 `P10` 안에
처음 렌더링되는 콘텐츠 단계다. `P11`–`P18`은 이 셸과 연결된 단계 콘텐츠
또는 보호된 하위 흐름을 검토하기 위한 표기이며 최종 라우트나 백엔드
상태가 아니다.

2026-07-27 소유자가 승인한 UX-OQ-002 기준은 모든 `P01`–`P21`과 `O01`–`O07`을 고유한
검토 키로 유지한다. 제안 분류와 병합·분리 경계는 [화면 후보 목록](screen-inventory.md)에
둔다. 특히 `P14` 동의와 `P15` 보기, `P16` 선택과 `P17` 결과를 합치지
않으며 `P20`은 문맥 안전 진입과 사후 목적지라는 두 표현을 한 검토 키로
묶는다. 이 분류는 최종 화면, route, component 또는 상태 계약이 아니다.

## 모든 화면에 적용되는 직교 상태

- 인증: 유효, 재인증 필요, 세션 만료, 계정 제한.
- 연결: 온라인, 느림, 재연결, 오프라인, 공급자 장애.
- 권한: 허용, 요청 전, 거절, 만료, 철회, 현재 단계에서 불가.
- 데이터: 최초/비어 있음, 로딩, 최신, 오래됨, 충돌, 제출 중, 완료.
- 안전: 기본, 차단 반영 중, 신고 진입, 즉시 나가기, 운영 일시정지.
- 접근성: 키보드 초점, 스크린리더 알림, 200% 확대, 감소 동작, 텍스트 대안.

## 승인된 전환 표현

- 단계 변화는 새 제목, 현재 청중, 남은 시간, 가능한 행동을 함께 갱신한다.
- 제출 중에는 중복 행동을 막되 나가기·신고를 막지 않는다.
- 오래된 상태를 감지하면 상대 선택을 추정해 낙관적으로 반영하지 않고 최신 상태를 다시 확인한다.
- 만료와 오류를 구분한다. 만료는 재시도로 이전 권한을 되살리지 않는다.
- 중요한 성공은 “내 행동이 저장됨”만 확인하고 상대 결과를 암시하지 않는다.

## 구현 경계

상태의 사용자 의미와 presentation 분류는 승인되었다. 정확한 화면 구현,
모달/시트/페이지 단위, 상태 enum, route, component와 운영자 navigation은
정하지 않는다.
