# Session Capability Summary

Approved product order: waiting/readiness, rules/intro, three games, free group conversation, initial interest, limited reveal, final choice/close, optional ten-minute mutual pair voice.

Backend authority, fail-closed grants, idempotent consequential commands, private choices, operator mute/remove/pause/cancel and no recording are approved principles. Exact waiting behavior, screen transitions, timer presentation, reconnect, late join, five-person continuation consent, no-match presentation, transport/state machine and event payloads remain Draft pending UX approval.

Use [session experience](../spec/session-experience.md) for approved product rules and [session wireflow](../spec/ux/session-wireflow.md) for unresolved interaction decisions. Do not implement from this summary.
