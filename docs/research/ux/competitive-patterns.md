# 경쟁 UX 패턴 채택 제안

## 범위

이 문서는 완료된 경쟁 연구를 다시 수행하지 않고, 기존 [UX 연구 인덱스](README.md), [한국 사용자 기대 경계](korean-user-expectations.md), [세션 게임 연구](session-game-patterns.md)를 D-024 검토용 채택·거부 제안으로 정리한다. 경쟁 서비스의 존재는 인과적 효용, 안전, 유지율 또는 한국 적합성을 입증하지 않는다.

## 검토된 패턴과 제안

| 범주/사례 | 기존 연구에서 확인한 메커니즘 | 프로젝트 제안 | 제한·보호장치 |
| --- | --- | --- | --- |
| Timeleft | 예약된 소규모 모임과 행사 후 연결 | 고정 시간, 출석 상태, 종료 후 별도 상호 동의 | 오프라인 장소 운영과 경제성은 재사용하지 않음 |
| Hinge | 프롬프트 기반 자기표현과 대화 시작 | 짧고 검토된 질문을 대화 씨앗으로 사용 | 공개 프로필 탐색과 외모 중심 탐색은 제외 |
| Tinder/Bumble | 상호성, 신고·안전 표면, 프로필 탐색 | 상호 동의와 언제든 접근 가능한 안전 행동만 참고 | 스와이프, 부스트, 인기 경쟁, 공개 수치 제외 |
| WIPPY/Noondate/MUNTO | 한국 소셜·데이트 발견 범주 | 한국어 어조와 기대를 별도 사용성 연구 입력으로 사용 | 현재 기능·시장 적합성은 직접 검증 전 주장하지 않음 |
| Meetup | 이벤트 중심 발견과 행동 규범 | 세션 전 규칙, 시간·장소·취소 명료성 | 공개 커뮤니티·주최자 모델은 제외 |
| Discord 음성 무대 | 역할, 음소거, 단계 상태, 재연결 | 청중·발화·연결·운영 제어를 분명히 표시 | 커뮤니티 방송 구조를 데이팅 관계로 복제하지 않음 |
| 파티 게임 | 개인 기기 입력, 차례, 공유 맥락 | 사적 입력과 공통 프롬프트, 점수 없는 차례 | 저작물·프롬프트·트레이드 드레스 복제 금지 |

## 채택 제안

- 예약·대기·현재 단계·남은 시간을 지속적으로 보여 예측 가능성을 높인다.
- 한 화면에 짧은 프롬프트와 예시를 주고 패스·반복·생각 시간·텍스트 대안을 둔다.
- 개인 입력은 먼저 사적으로 받고 공개되는 내용과 청중을 별도로 알린다.
- 관심 선택, 공개 동의, 최종 선택을 서로 다른 결정으로 분리한다.
- 음성 셸에서 마이크·연결·청중·운영 상태와 신고·나가기를 지속적으로 제공한다.
- 결과는 내 다음 권한만 보여 주고 선택 수·거절 이유·상대 선택을 공개하지 않는다.

## 거부 제안

- 무한 스와이프, 프로필 순위, 유료 노출, 인기·정답·승자 수치.
- 상호 관심만으로 사진·연락처·사적 방을 자동 공개하는 흐름.
- 재사용 가능한 방 링크, 카메라 강제, 녹음, 공개 미디어 URL.
- 빠른 답변·유머·말하기 자신감을 매력이나 안전 점수로 다루는 흐름.
- 얼굴 공개를 획득하는 보상, 게임 성공의 상, 상대방이 받을 권리로 표현하는 흐름.
- 경쟁사의 고유 콘텐츠, 시각 정체성, 게임 규칙 또는 카피를 모사하는 작업.

## 검증이 필요한 가설

| 가설 | 검증 질문 | 실패 신호 |
| --- | --- | --- |
| 구조화된 게임이 대화 공백을 줄인다 | 패스권을 유지한 채 시작 부담이 줄어드는가 | 지시 이해 실패, 압박, 높은 패스율 |
| 지연된 사진 공개가 사적 호기심을 돕는다 | 동의와 비공개 범위를 정확히 이해하는가 | 보상 오해, 실망·배신감, 강요감 |
| 고정 세션이 신뢰를 높인다 | 대기·취소·재예약을 예측할 수 있는가 | 결석 비난, 빈자리 불안, 늦은 통보 |
| 음성 중심이 성격 표현을 돕는다 | 청각·언어·불안 접근성 대안이 충분한가 | 지배적 발화, 침묵 낙인, 기술 포기 |

## 기존 출처 원장

- [Timeleft](https://timeleft.com/): 예약형 소규모 모임을 소개하는 마케팅 자료. 사회적 성과의 인과 증거가 아니다.
- [Hinge 도움말](https://help.hinge.co/): 프로필·상호작용 지원 표면을 설명한다. 프롬프트 효과를 입증하지 않는다.
- [Tinder 안전 센터](https://www.tinder.com/safety): 신고·안전 표면의 존재를 설명한다. 비공개 그룹 세션의 직접 모델이 아니다.
- [Discord Stage Channels](https://support.discord.com/hc/en-us/articles/1500005513722-Stage-Channels-FAQ): 음성 역할과 운영 개념을 설명한다. 데이팅 안전성을 입증하지 않는다.
- [Jackbox 지원](https://www.jackboxgames.com/support): 개인 기기와 공유 게임 맥락의 범주 참고다. 콘텐츠 복제 근거가 아니다.
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/): 접근 가능한 상호작용 기준 참고다. 심리적 저압 경험을 입증하지 않는다.

## 승인 경계

채택·거부 항목은 모두 제안이다. [마찰과 안티패턴](competitor-friction-and-antipatterns.md), [설계 원칙](../../spec/ux/design-principles.md), 대상 참가자 사용성 시험을 함께 검토한 뒤에도 D-024 소유자의 명시적 승인 없이는 UI나 구현 기준이 되지 않는다.
